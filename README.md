💰 Expense Tracker

A simple and interactive Expense Tracker web application built with Python and Streamlit.
The app helps users record, manage, and analyze their daily expenses through an easy-to-use interface.

🚀 Features

- ➕ Add new expenses
- 📝 Record expense details such as amount, category, date, and description
- 📊 View expense summaries and spending patterns
- 🗂️ Categorize expenses
- 📈 Visualize expenses using charts
- 💵 Calculate total spending
- 🔎 Review previously added expenses
- 🖥️ Interactive and user-friendly Streamlit interface

🛠️ Tech Stack

- Python
- Streamlit – Web application framework
- Pandas – Data manipulation and analysis
- Matplotlib – Data visualization

⚙️ Installation

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/Expense-Tracker.git
cd Expense-Tracker

2. Create a virtual environment

python -m venv venv

Activate it:

Windows:

venv\Scripts\activate

macOS/Linux:

source venv/bin/activate

3. Install dependencies

pip install -r requirements.txt

If you don't have a "requirements.txt" file yet:

pip install streamlit pandas matplotlib

4. Run the application

streamlit run app.py

The application will open in your browser.

📊 How It Works

1. Enter the details of your expense.
2. Select an expense category.
3. Enter the amount and other required information.
4. Submit the expense.
5. The application stores the expense data.
6. View your expenses and analyze your spending using the available summaries and visualizations.
